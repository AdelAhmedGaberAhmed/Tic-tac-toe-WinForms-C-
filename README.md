# ❌⭕ Tic Tac Toe (XO) Game - Windows Forms

## 📌 Overview
This is a simple **Tic Tac Toe (XO)** game developed using **C# Windows Forms**.  
The project provides an interactive graphical interface for two players to compete in the classic XO game.

The main focus of this project is applying **OOP concepts** and building a user-friendly desktop application.

---

## 🛠️ Technologies Used
- C#
- Windows Forms (.NET Framework)
- Object-Oriented Programming (OOP)
- Event-driven programming

---

## 🎮 Game Features
- Two-player mode (Player X vs Player O)
- Interactive GUI using buttons
- Automatic win detection (rows, columns, diagonals)
- Draw detection when board is full
- Game reset functionality
- Simple and user-friendly interface
